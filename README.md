# template-plugin

Template repository for writing a Horae plugin: manifest, MCP stdio server, recorded-input tests and CI.

> 🚧 **Planned.** Nothing to install yet. Follow progress on the [Horae roadmap project](https://github.com/orgs/horae-dev/projects/1).

## What this repository will be

A GitHub template that gives you a working Horae plugin in minutes: `plugin.yaml` with declared permissions, an MCP stdio server built on `horae-sdk`, recorded-input tests, CI, `graft.yaml` and `AGENTS.md`.
